# ConformalHydride

**Conformal certification of reversible metal hydrides exposes the statistical limits of machine-learning screening for hydrogen storage**

![Python](https://img.shields.io/badge/python-3.12-blue) ![GPU](https://img.shields.io/badge/GPU-Tesla%20T4%20(free%20tier)-green) ![Runtime](https://img.shields.io/badge/full%20run-~18%20min-orange)

<p align="center"><img src="docs/graphical_abstract.png" width="820"></p>

Machine-learning screening of hydrogen-storage materials is almost always reported as point predictions.
This repository asks what can actually be **certified**. Using the curated ML-HydPARK database
(398 measured metal hydrides), gradient-boosted models and a composition-attention transformer (HyCAN)
are wrapped in conformal prediction to obtain finite-sample coverage and false-discovery-rate (FDR) control
for selection into the reversible window ΔH<sub>des</sub> = 25–45 kJ (mol H₂)⁻¹.

**Key results, all regenerated by one notebook:**
- Naive point selection into the window carries an empirical **FDR of 0.23**; regression-based two-sided
  certification is **impossible** (the calibrated residual span equals the window width — the *certification wall*).
- A classification-score conformal construction restores FDR-controlled discovery
  (empirical FDR 0.136 ≤ q = 0.2, power 0.47).
- On 336 screenable refractory high-entropy-alloy candidates: **217 nominated by point prediction, 0 certifiable**;
  229 carry a certified one-sided stability claim. Five independent measurements (mean 57.5 kJ (mol H₂)⁻¹,
  4/5 outside the window) corroborate the zero.
- Marginal 90 % coverage survives leave-one-literature-source-out shift (weighted coverage 0.894/0.902).

## One-click reproduction

Everything in the paper — **all figures (F1–F8), all tables (T1–T12), all model checkpoints** — is produced
by a single notebook, `ConformalHydride_MASTER.ipynb`, in one *Run All* on Kaggle's free GPU tier.

1. **Upload the data once.** Take `ConformalHydride_DATA.zip` from this repository, extract it, and upload the
   `hydpark/` folder as a Kaggle **Dataset** (suggested name: `conformalhydride-data`).
2. **Create the notebook.** On Kaggle, *Create → Notebook → File → Import Notebook* and select
   `ConformalHydride_MASTER.ipynb`. In the right-hand panel, *Add Input* → your `conformalhydride-data` dataset.
3. **Enable the accelerator.** Settings → Accelerator → **GPU (T4 is sufficient)**. Internet *on* is recommended
   (the notebook can also self-fetch any missing file from the public source repository).
4. **Run All.** ≈ 18 minutes end-to-end on a single T4 (≈ 11 min model training, ≈ 6 min leave-one-source-out).

The notebook finishes by packaging `ConformalHydride_MASTER_results.zip` containing `figures/` (300-dpi PNG +
vector PDF), `tables/` (CSV), `checkpoints/` (all prediction matrices, splits, audited dataset) and a
machine-readable `run_report.txt/json` (environment, timings, headline numbers). A smoke-test mode is available
by setting the environment variable `CHY_FAST_DEV=1` (not for reportable results).

## Repository contents

| Path | Description |
|---|---|
| `ConformalHydride_MASTER.ipynb` | The single end-to-end pipeline (audit → models → conformal comparison → FDR-controlled selection → pool certification → source-shift → repairs → diagnostics). |
| `ConformalHydride_DATA.zip` | Data bundle: cleaned ML-HydPARK (n = 398), elemental-hydride formation energies, the 672-alloy rHEA screening pool, the 5 measured HEA anchors, and `MANIFEST.md` with full provenance. |
| `results/` | A reference copy of `ConformalHydride_MASTER_results.zip` from the run reported in the paper. |

## Requirements

Kaggle's default GPU image needs **no installation**. For local execution: Python ≥ 3.12 with
`numpy`, `pandas`, `scikit-learn`, `scipy`, `lightgbm`, `torch`, `matplotlib`. CPU-only execution works but is slower.

## Data provenance and citation

The underlying data are the public **ML-HydPARK** curation of the U.S. DOE HydPARK compilation and the
rHEA candidate pool. If you use this repository, please cite the dataset and curation papers:
